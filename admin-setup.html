Dreamscapes · Administrator onboarding

Activate the Control Room.

The database and Control Room are ready. The existing CrowRules administrator table currently has no active administrator records, so the first administrator must be explicitly assigned.

Security: do not make every signed-up user an administrator. Run these steps only while signed in to the correct CrowRules Supabase project as its database owner.

01 · Confirm your account exists

Open Supabase Dashboard → Authentication → Users and confirm the exact email address you will use to sign in to the Dreamscapes Control Room.

Open CrowRules Auth Users ↗

02 · Add the first administrator

Open SQL Editor for the same project. Replace the placeholder with your exact account email, then run the query. It only adds the matching account; if no account matches, no row is inserted.

Open CrowRules SQL Editor ↗

insert into public.cr_admins (user_id, role, is_active)
select id, 'admin', true
from auth.users
where lower(email) = lower('YOUR_LOGIN_EMAIL@example.com')
on conflict (user_id) do update
set role = 'admin',
    is_active = true,
    updated_at = now();

-- Verify that your account is active:
select a.user_id, u.email, a.role, a.is_active
from public.cr_admins a
join auth.users u on u.id = a.user_id
where lower(u.email) = lower('YOUR_LOGIN_EMAIL@example.com');

03 · Sign in and verify

Return to the Control Room and sign in with that same email/password or the configured Google account. You should see the dashboard only after the active admin check succeeds.

What is already in place

  • Six Dreamscapes database tables with Row Level Security enabled.
  • Admin-only submission, project, team, Pitch Room, and Premiere Room management.
  • Authenticated submitters can create and read only their own submissions.
  • Public visitors can read only Premiere Room records marked published.
